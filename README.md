# gpu_tinker

Графічна програма для KDE Plasma на Wayland: показує відеокарти, використання відеопам’яті, процеси й монітори та допомагає звільнити обрану карту для обчислень.


Потрібні Python 3 і PySide6 (`requirements.txt`). Системні утиліти: `kscreen`, `pciutils`; для NVIDIA/Intel — `nvidia-smi`/`intel_gpu_top`. `amdgpu_top` необов’язковий: використовується лише для точнішої назви AMD-карти. Відсутні утиліти можна встановити під час запуску через пакетний менеджер.

```bash
python3 gpu_tinker.py
```
